# 个人技能导航

优先使用本地 Skill、任务 Prompt 与现有工具，推荐单个技能、必要组合或无需技能的方案。新方案先供用户复核，明确确认后执行真实任务。默认中文交流，用户指定语言优先。

## 入口

- 用户指定本技能或要求技能选择、比较、组合时导航；显式调用的简单任务可以推荐无需技能，仍给出 Prompt。仅查看或变更偏好/流程时直接管理对应记录，不运行无关导航。
- 普通概念解释、日常改写不自动导航；用户已指定专业技能且未要求比较时直接使用它。补充材料、进度询问和“继续/确认执行”沿用当前明确方案，不重新导航。描述匹配不能保证触发；不修改全局指引或建立常驻进程。
- 从对话提取目标、材料、交付及硬约束，标明假设。保留用户明确选择的技能和产品；不适用时解释原因。查得到的事实自行核对；只有缺失答案会改变方案或阻止执行时才问一个关键问题，说明答案怎样影响选择。

## 新导航的连续主线

1. **增量索引与候选检索。** 调用 `scripts/skill_index.py query`，用能力/输入输出关键词，必要时补英文同义词；补入当前宿主提供的有效插件根目录，不扫描全部缓存版本。读取适用偏好，从任务提取标签；同义标签最多调整查询一次。命令、范围与失败降级见 [索引操作](references/index.md)。字面零命中不代表没有技能，必要时换词或看简短清单。
2. **先检查可复用流程。** 只读查看已有流程；缺失即继续选择，不创建记录。用本次类型、已知条件与当前可用技能筛选少量候选。命中时先核对其阶段与偏好，替换本次材料和参数；不能合理复用时才展开新的候选比较。查询截断、绑定变化及保存规则见 [流程复用](references/workflows.md)。历史流程不是本次执行授权。
3. **核对实际能力。** 阅读拟用流程绑定的技能，或首选与必要替代项的完整 `SKILL.md`；通常从 3–5 个候选开始，仅为明确缺口扩展。支持资源、工具和依赖只在影响选择/交接时检查，规划时不提前运行候选任务。先满足当前要求，再采用适用偏好；偏好命中不证明能力。
4. **建立关键对应关系并精简组合。** 每个关键要求写明负责的技能/Prompt/工具、实际依据和未解决条件。简单任务用短句，复杂任务用表格，见 [对应关系](references/mapping.md)。普通能力足够则无需技能；单个足够则选单个；相似者选一个首选，只有真实取舍才列少量替代。组合要有各自必要职责与交接，逐项问“去掉它失去什么关键支持”，一次精简一个再核对。复杂交接按需读 [组合与交接](references/composition.md) 并使用只读检查。
5. **提交 Prompt。** 关键要求都有负责方式、关键前提已核验或明确列为待确认，且没有被忽略的不兼容交接时，停止扩展候选。未满足这些条件就标明具体缺口，不冒充可执行。按下述输出约定提交本次方案；用户确认前停在复核点。

选择以当前要求、实际文件、工具条件和准备成本为依据，不编造收益分数、使用历史或最优保证。条件接近时优先准备较少且已验证可用者。未选中不构成删除理由，不能为组合忽略原技能约束或自行修改其他技能。

## 输出与验收

输出简短的推荐、关键依据、执行 Prompt 和必要待确认项；相关偏好/流程注明记录 ID，没有则省略。复杂程度决定短句或表格，不强制建立 JSON 方案文件。

Prompt 使用核对过的实际技能名称与宿主支持的调用方式，包含本次目标、材料位置、交付/验收、必要条件和授权范围。组合补阶段职责、输入输出及来源保留要求；无需技能写直接处理方式。不再次调用 skill-guide，也不擅自加入安装、删除、发布或配置修改。

完成规划前核对：关键要求均有负责人或明确缺口；依据来自实际说明/工具；未知条件未伪装成可用；Prompt 与推荐一致。结构检查通过不证明引用真实或内容正确，执行后仍按任务验收。

## 复核与执行

- “确认执行/按这版执行”对应当前清晰版本；仅修改意见则更新对应关系和 Prompt 后等待；“按以下修改版执行”直接使用修改版，不重复确认同一授权。
- 执行前 `check --id` 或 `check --path` 只核验所选技能；流程也核对相关绑定。内容变化先读受影响部分，无关目录变化不重新规划。只有目标、范围、必要组合或关键可用条件实质改变时才复核受影响方案。
- 确认后执行真实任务；遵守专业技能必要流程、宿主权限和已授权范围。失败先做范围内修复；同一障碍重复且无新证据时报告具体阻塞和下一步，不循环重试或静默引入新技能。

## 偏好与流程管理

- 当前明确指令优先，项目规则优先于适用个人规则；同级实质冲突仅复核冲突部分。精确技能身份不按同名自动迁移；普通更新不自动取消排除。规则与历史流程不授予工具或外部操作权限。
- “这次/本对话”仅留在当前上下文；明确“记住/以后/更新此流程”才持久化，范围含糊只复核待保存内容，已有清楚授权直接实施。单次失败不自动排除，成功不自动记录。仅保存最小规则或已确认/使用流程摘要，不保存完整 Prompt、聊天、材料或材料路径。
- 管理偏好、冲突及绑定变化时读 [偏好管理](references/preferences.md)，用 `skill_preferences.py`；管理流程时读 [流程复用](references/workflows.md)，用 `skill_workflows.py`。两者文件独立，可查看、修改、停用/启用或按 ID 删除。写入前有相应授权才传 `--authorized`；失败保留原记录并报告，不改权限或另存。偏好/流程读取失败时说明未应用历史数据，再继续合理选择。

## 能力缺口与升级

默认不联网、不自动安装。先尝试本地 Skill＋Prompt、必要组合、现有工具或小范围适配；区分缺流程、工具、依赖、数据和权限，新增 Skill 不会自动补齐条件。

仅为未满足的关键要求、可观察的大量重复操作，或值得封装的稳定重复流程提出扩展，考虑检索、适配、验证与维护成本。进入此分支才读 [外部能力与封装](references/extension.md)，给出具体缺口和有边界的调查/实施 Prompt；已有清晰授权直接在范围内执行，缺授权或扩大范围时才复核。候选可为 Skill 或普通项目，未经验证不称为可用，只读调查不扩大到安装。
